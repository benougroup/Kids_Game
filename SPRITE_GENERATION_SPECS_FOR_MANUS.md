# SPRITE GENERATION SPECIFICATIONS FOR MANUS AI

## Overview
Generate pixel art sprites for a kid's RPG game called "Lumenfall".
Each sprite file contains exact specifications for one character/creature/object.
Follow the format precisely for consistency.

## File Format Convention
- Each sprite = one file
- Format: `[CATEGORY]_[NAME].md`
- Categories: BUILDINGS, CREATURES, PROPS, NPCS

## Universal Requirements
- Format: PNG with transparent background (RGBA)
- Pixel art style: 16-32 bit retro
- Color palette: Warm, kid-friendly colors
- No black boxes or artifacts
- Canvas size: EXACTLY as specified
- Centered in canvas
- One image per file (no animation sheets)

# INSTRUCTIONS FOR MANUS AI

## How to Use These Specifications

1. **Read each file completely** - All details are important
2. **Follow canvas size exactly** - This is critical for game integration
3. **Maintain pixel art style** - Retro 16-32 bit aesthetic
4. **Use specified colors** - Color palettes keep consistency
5. **Center in canvas** - Sprites should be well-positioned
6. **Transparent background** - PNG with RGBA alpha channel
7. **No artifacts** - Clean edges, no black boxes or glitches
8. **One image per specification** - Don't combine multiple sprites

## Quality Checklist

- [ ] Canvas size matches specification exactly
- [ ] Image is centered in canvas
- [ ] Background is transparent (no white/black edges)
- [ ] Colors match palette suggestions
- [ ] Style is consistent (all pixel art, similar detail level)
- [ ] No duplicate/overlapped elements
- [ ] Suitable for kids (no scary/violent imagery)
- [ ] File saved as PNG with transparency
- [ ] Filename matches specification (e.g., BUILDINGS_tavern_blue_roof.png)

## Naming Convention

Format: `[CATEGORY]_[NAME].png`

Examples:
- `BUILDINGS_tavern_blue_roof.png`
- `CREATURES_rabbit_idle.png`
- `PROPS_tree_oak_large.png`
- `NPCS_guard_aldric.png`

## Delivery Format

Place all PNG files in a folder:
```
/sprites_for_lumenfall/
├── BUILDINGS_tavern_blue_roof.png
├── BUILDINGS_house_thatch_small.png
├── CREATURES_rabbit_idle.png
├── CREATURES_rabbit_walk.png
... etc
```

Zip and share with development team.

## Integration Notes

- These sprites integrate with a Phaser 3 game
- Canvas sizes are locked - changing them breaks game positioning
- Transparency is mandatory - opaque backgrounds cause visual errors
- File names must match exactly - game looks up sprites by filename
- All sprites for one category (e.g., all buildings) must be consistent in style
